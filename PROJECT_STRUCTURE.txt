================================================================================
주요 데이터 흐름
================================================================================

1. 팩트체크 시스템
   주장 입력 → Evidence 수집 (하이브리드 검색)
   → Evidence 평가 (관련도 측정)
   → 신뢰도 계산 (0-10점)
   → 최종 판정 (True/False/Uncertain)

2. 페르소나 시스템
   댓글 수집 → 페르소나 생성 (LLM)
   → 토론 시작 → AI 메시지 생성
   → 감정 추적 → 주제 전환/종료

3. YouTube 파이프라인
   YouTube URL 입력 → 오디오 다운로드
   → 음성-텍스트 변환 → 스크립트 요약
   → 댓글 수집 → 좌우파 분류
   → 페르소나 배틀 → 토론 시뮬레이션

사용된 AI/ML 모델 명세
================================================================================

📊 팩트체크 시스템 (factcheck/)
   
   1. 문장 임베딩 모델
      모델명: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
      용도: 하이브리드 검색 (의미 기반 유사도 측정)
      크기: ~420MB
      특징: 다국어 지원 (한국어, 영어 등 50개 언어)
      
   2. LLM 판정 모델 (선택적)
      모델명: Hugging Face Transformers pipeline
      용도: Evidence 기반 최종 판정
      특징: 선택적 사용 (Rule-based로도 작동 가능)

📊 페르소나 시스템 (persona/)
   
   1. 페르소나 생성 & 토론 모델
      모델명: skt/kogpt2-base-v2
      용도: 
        - 댓글 기반 페르소나 생성 (comment_persona_engine.py)
        - AI 토론자 대화 생성 (ai_debater.py)
      크기: ~525MB
      특징: 
        - 한국어 특화 GPT-2 모델
        - CPU 모드 지원 (torch.float32)
        - 경량 버전으로 빠른 응답
      라이선스: Apache 2.0
      
   2. 감정 분석 모델 (선택적)
      모델명: jhgan/ko-alpaca-7b
      용도: 댓글 감정 및 논조 분석 (analyzer.py)
      크기: ~13GB
      특징: 
        - LLM 기반 감정 분석 (선택적)
        - 기본은 규칙 기반 분석 사용 (메모리 효율)
      하드웨어: GPU 권장 (VRAM 8GB+)

📊 YouTube 파이프라인 (structure/)
   
   1. 음성-텍스트 변환 모델
      모델명: OpenAI Whisper (small)
      용도: YouTube 오디오 → 텍스트 변환 (transcribe.py)
      크기: ~461MB
      특징:
        - 다국어 지원 (한국어 포함)
        - CPU/GPU 모두 지원
        - 높은 정확도
      옵션: tiny, base, small, medium, large
      
   2. 토픽 모델링 (comments_topic/)
      
      a) 문장 임베딩 모델
         모델명: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
         용도: 댓글 임베딩 (BERTopic 입력)
         크기: ~420MB
         
      b) 토픽 추출 모델
         모델명: BERTopic
         용도: 댓글 주제 클러스터링 및 추출
         특징: 
           - HDBSCAN 클러스터링
           - UMAP 차원 축소
           - 한국어 토픽 추출

트러블슈팅
================================================================================

❌ CUDA out of memory
   → 8bit/4bit 양자화 사용
   → 배치 크기 줄이기
   → GPU 메모리 확인

❌ 모델 다운로드 실패
   → 인터넷 연결 확인
   → huggingface-cli login
   → 프록시 설정 확인

❌ API 연결 실패
   → 서버 실행 여부 확인
   → 포트 충돌 확인
   → CORS 설정 확인

❌ 한글 깨짐
   → UTF-8 인코딩 확인
   → 터미널 인코딩 설정
   → Windows: chcp 65001

❌ Import 오류
   → 가상환경 활성화 확인
   → __init__.py 파일 확인
   → PYTHONPATH 설정 확인
