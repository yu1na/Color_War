===================================================================================
                    ColorWar 환경 변수 설정 가이드
===================================================================================

이 파일은 ColorWar 프로젝트에서 필요한 API 키 및 환경 변수 설정 방법을 안내합니다.

===================================================================================
📋 설정 방법
===================================================================================

1. 프로젝트 루트 디렉토리에 .env 파일을 생성하세요
2. 아래 내용을 복사하여 .env 파일에 붙여넣으세요
3. 각 API 키를 발급받아 your_xxx_here 부분을 실제 값으로 교체하세요
4. .env 파일은 절대 Git에 커밋하지 마세요! (.gitignore에 포함되어 있습니다)

===================================================================================
🔑 필수 환경 변수
===================================================================================

# ==================== YouTube API ====================
# YouTube 댓글 수집을 위한 API 키
# 발급: https://console.cloud.google.com/apis/credentials
# 
# 발급 단계:
# 1. Google Cloud Console 접속
# 2. 프로젝트 생성
# 3. YouTube Data API v3 활성화
# 4. 사용자 인증 정보 → API 키 생성
# 
YOUTUBE_DATA_API_KEY=your_youtube_api_key_here

===================================================================================
🔑 선택적 환경 변수 (기능 향상)
===================================================================================

# ==================== Naver 뉴스 검색 API ====================
# 팩트체크 시 한국 뉴스 검색 품질 향상
# 발급: https://developers.naver.com/products/login/api/
# 
# 발급 단계:
# 1. 네이버 개발자센터 접속
# 2. 애플리케이션 등록
# 3. 검색 API → 뉴스 검색 선택
# 4. Client ID 및 Client Secret 발급
# 
# ⚠️  없어도 작동 가능 (DuckDuckGo 검색 사용)
NAVER_CLIENT_ID=your_naver_client_id_here
NAVER_CLIENT_SECRET=your_naver_client_secret_here

# ==================== OpenAI API ====================
# 고급 LLM 기능 사용 시 필요 (GPT-4 등)
# 발급: https://platform.openai.com/api-keys
# 
# ⚠️  없어도 작동 가능 (로컬 모델 사용)
# 비용: API 호출 시마다 과금됨
OPENAI_API_KEY=your_openai_api_key_here

# ==================== Ollama 로컬 LLM ====================
# 로컬 LLM 서버 사용 시 설정
# 설치: https://ollama.ai/
# 
# Ollama 설치 후 모델 다운로드:
# ollama pull llama3.2
# ollama pull solar
# 
# ⚠️  없어도 작동 가능 (기본 모델 사용)
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2

===================================================================================
📝 .env 파일 템플릿
===================================================================================

다음 내용을 복사하여 프로젝트 루트에 .env 파일로 저장하세요:

---
# ColorWar 환경 변수

# 필수: YouTube API (댓글 수집)
YOUTUBE_DATA_API_KEY=your_youtube_api_key_here

# 선택: Naver API (팩트체크 품질 향상)
NAVER_CLIENT_ID=your_naver_client_id_here
NAVER_CLIENT_SECRET=your_naver_client_secret_here

# 선택: OpenAI API (고급 LLM)
# OPENAI_API_KEY=your_openai_api_key_here

# 선택: Ollama (로컬 LLM)
# OLLAMA_URL=http://localhost:11434
# OLLAMA_MODEL=llama3.2
---

✅ 설정 확인 방법
===================================================================================

1. .env 파일 생성 후 서버 실행:

===================================================================================
🐛 문제 해결
===================================================================================

Q: YouTube API 할당량 초과 오류가 발생합니다
A: Google Cloud Console에서 할당량을 확인하세요. 기본 할당량은 하루 10,000 units입니다.
   댓글 100개 수집 시 약 1 unit 소비됩니다.

Q: Naver API 없이도 팩트체크가 작동하나요?
A: 네, DuckDuckGo 검색이 자동으로 사용됩니다. 하지만 한국 뉴스 품질은 떨어질 수 있습니다.

Q: Ollama를 설치하지 않아도 되나요?
A: 네, 기본적으로 로컬 경량 모델(skt/kogpt2)을 사용합니다.

Q: OpenAI API를 꼭 써야 하나요?
A: 아니요, 로컬 모델로도 모든 기능이 작동합니다. OpenAI는 선택사항입니다.
