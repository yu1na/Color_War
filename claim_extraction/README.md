# 주장 추출 모듈 (Claim Extraction)

**스크립트 + 댓글 통합 분석**으로 팩트체크 포인트 1~3개를 자동 생성합니다.

## 🎯 기능

- **스크립트 + 댓글 통합 분석**: 
  - **1단계**: 스크립트에서 사실 주장 추출 (인물+직책+행동)
  - **2단계**: 댓글에서 논쟁 키워드 추출 (빈도 분석)
  - **3단계**: 교집합 → 팩트체크 포인트 1~3개
- **가공된 문장 생성**: 불필요한 표현 제거, 핵심만 남김
- **점수 기반 우선순위**: 
  - 스크립트+댓글 매칭: 0.7~1.0점 ✅
  - 스크립트만: 0.6점
- **프론트엔드 통합**: 클릭 시 자동 팩트체크

## 🚀 사용 방법

### 1. 프론트엔드에서 사용

1. **영상 주제 검출** 먼저 실행
2. **팩트체크** 섹션에서 "📋 주장 추출" 버튼 클릭
3. 추출된 주장을 선택하면 자동으로 입력창에 입력됨
4. **팩트체크 실행** 버튼으로 검증

### 2. API 호출

```bash
curl -X POST http://localhost:8000/api/claim-extraction/extract \
  -H "Content-Type: application/json" \
  -d '{
    "video_id": "BdIOeGXbb48",
    "top_k": 5
  }'
```

**응답 예시:**

```json
{
  "success": true,
  "video_id": "BdIOeGXbb48",
  "claims": [
    {
      "claim": "이재명 대통령은 역대 최다 득표로 제21대 대통령에 당선됐습니다",
      "score": 0.8,
      "length": 45
    },
    {
      "claim": "최종 득표율 49.42%, 1728만 7513표를 얻었습니다",
      "score": 0.75,
      "length": 40
    }
  ],
  "message": "2개의 주장을 추출했습니다."
}
```

### 3. Python에서 직접 사용

```python
from claim_extraction.extractor import ClaimExtractor

extractor = ClaimExtractor()

# 텍스트에서 직접 추출
text = "이재명 대통령은 역대 최다 득표로 당선됐습니다..."
claims = extractor.extract_claims(text, top_k=5)

# 파일에서 추출
claims = extractor.extract_from_file(video_id="BdIOeGXbb48")

for claim in claims:
    print(f"주장: {claim['claim']}")
    print(f"점수: {claim['score']}")
```

## 📊 추출 로직

### 1. 팩트체크 가능 패턴 (댓글 특화)

- **수치 주장**: "49.42%", "1728만 명", "10개" 등
- **날짜/사건**: "오늘", "작년", "내년 총선" 등
- **증감 표현**: "증가", "급등", "망했다", "성공" 등
- **비교 표현**: "역대 최다", "전부", "모두" 등
- **인용 주장**: "밝혔다", "됐다", "한다" 등
- **단언 표현**: "사실", "거짓", "가짜", "조작" 등
- **정치 주장**: "대통령", "탄핵", "선거", "투표" 등

### 2. 점수 계산

| 요소 | 점수 |
|------|------|
| 패턴 매칭 | +0.3 |
| 숫자 포함 | +0.2 |
| 날짜 표현 | +0.15 |
| 인물/기관명 | +0.1 |
| 질문/추측 | -0.5 |
| 부적절한 길이 | -0.2 |

### 3. 제외 패턴

- 질문 (`?`)
- 추측 ("~할까", "~일까", "~겠지")
- 추정 ("보입니다", "것 같습니다")
- 의견 ("바랍니다", "기대합니다")
- 욕설 및 비속어
- 의미없는 감탄사 ("ㅋㅋㅋ", "ㅎㅎㅎ")

3. **NBN의거짓말가짜뉴스에속지맙시다** (점수: 0.7)


## ⚠️ 주의사항

1. **"주제 검출" 먼저 실행 필요**: 비디오 ID가 없으면 주장 추출 불가
2. **데이터 파일 우선순위**:
   - 1순위: `comments/{video_id}_comments.txt` (댓글, 사용자 주장)
   - 2순위: `scripts/{video_id}.txt` (스크립트, 뉴스 원문)
3. **structure 모듈 독립성**: structure 모듈 코드는 수정하지 않음 (데이터만 읽음)
4. **댓글 품질**: 댓글 품질에 따라 추출 결과가 달라질 수 있음
