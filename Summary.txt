===================================================================================
                        ColorsWar 프로젝트 파일 구조 요약
===================================================================================

이 프로젝트는 YouTube 정치 댓글을 분석하고, AI 기반 페르소나를 생성하여 토론을 시뮬레이션하며,
뉴스 팩트체크 기능까지 제공하는 종합 정치 분석 시스템입니다.

===================================================================================
📊 1. YouTube 댓글 수집 및 주제 분석 모듈
===================================================================================

[structure/comments_topic/src/extract_comments.py]
- 역할: YouTube 영상의 댓글을 수집하는 핵심 모듈
- 기능:
  • YouTube Data API를 사용하여 댓글 및 답글 수집
  • .env 파일에서 API 키 로드 (YOUTUBE_DATA_API_KEY)
  • 수집된 댓글을 extract_comments/ 폴더에 txt 파일로 저장
  • Windows 환경에서 한글 출력 지원

[structure/comments_topic/src/comments_topic.py]
- 역할: 수집된 댓글에서 주요 토론 주제를 자동 추출
- 기능:
  • BERTopic + HDBSCAN을 사용한 토픽 모델링
  • 한국어 정치 댓글에 특화된 주제 분류 (8개 카테고리)
  • 각 주제별 대표 댓글 3개씩 선정
  • "정권 교체", "사법개혁", "지역 갈등" 등 정치 이슈 자동 분류
  • comments_result/ 폴더에 결과 저장

===================================================================================
🎬 2. YouTube 콘텐츠 처리 파이프라인 (자동화)
===================================================================================

[structure/youtube_pipeline/audio.py]
- 역할: YouTube 영상에서 오디오 다운로드
- 기능:
  • yt-dlp를 사용하여 오디오 추출 (mp3 형식)
  • audio/ 폴더에 저장
  • 실패 시 mock 파일 생성 (테스트용)

[structure/youtube_pipeline/transcribe.py]
- 역할: 오디오를 텍스트로 변환 (STT)
- 기능:
  • Whisper 모델 사용 (음성 인식)
  • 한국어 전사(transcription) 지원
  • scripts/ 폴더에 텍스트 저장
  • Whisper 미설치 시 mock 텍스트 생성

[structure/youtube_pipeline/summarizer.py]
- 역할: 전사된 텍스트를 요약하고 키워드 추출
- 기능:
  • 긴 문장 우선 추출하여 핵심 내용 요약
  • "사건", "발표", "주장" 등 키워드 기반 구조화된 요약
  • 빈도 기반 키워드 추출 (상위 10개)
  • summaries/ 폴더에 저장

[structure/youtube_pipeline/comments.py]
- 역할: YouTube 댓글 수집 (파이프라인 통합용)
- 기능:
  • YouTube Data API 연동
  • 10자 이상 댓글만 필터링
  • comments/ 폴더에 저장
  • API 키는 env/.env에서 로드

[structure/youtube_pipeline/analyzer.py]
- 역할: 댓글을 영상 요약과 비교하여 정치 성향 분류
- 기능:
  • 요약-댓글 간 유사도 계산 (단어 교집합 기반)
  • 키워드 기반 좌파/우파 자동 분류
  • 좌파 키워드: 복지, 평등, 환경, 인권 등
  • 우파 키워드: 시장, 안보, 전통, 규제완화 등
  • reclassifier와 연동하여 재분류

[structure/youtube_pipeline/saver.py]
- 역할: 분석 결과를 파일로 저장
- 기능:
  • 좌파/우파 댓글을 각각 분리하여 저장 (comments_leftright/)
  • 전체 분석 결과 통합 저장 (results/)
  • 통계 정보 포함 (좌/우 댓글 수, 신뢰도 등)

🤖 3. 페르소나 생성 및 AI 토론 시스템
===================================================================================

[persona/model/comment_persona_engine.py]
- 역할: 댓글을 학습하여 AI 페르소나 생성 (핵심 엔진)
- 기능:
  • skt/kogpt2-base-v2 경량 모델 사용 (CPU 최적화)
  • 좌파/우파 댓글 각각 5개 이상 수집 시 페르소나 생성
  • LLM이 말투, 감정, 가치관을 JSON으로 요약
  • 페르소나 정보: 핵심가치, 말투특징, 감정스타일, 키워드, 예시 댓글
  • JSON 파싱 실패 시 기본 페르소나 자동 생성

[persona/backend/analyzer.py]
- 역할: 댓글 분석 엔진 (규칙 기반 + 선택적 LLM)
- 기능:
  • 좌파/우파 논점 추출
  • 감정 패턴 분석
  • 논쟁적 키워드 식별
  • jhgan/ko-alpaca-7b 모델 사용 (선택적)
  • LLM 없이도 규칙 기반으로 작동 가능

[persona/backend/ai_debater.py]
- 역할: 페르소나를 기반으로 실시간 토론 댓글 생성
- 기능:
  • skt/kogpt2-base-v2 사용 (공유 파이프라인)
  • 좌파/우파 AI 토론자 각각 생성
  • 이전 대화 맥락(최근 4개) 참고하여 응답 생성
  • 현재 주제에 맞는 댓글 스타일 유지
  • 150토큰 이내로 짧고 자연스러운 댓글 생성

[persona/backend/sentiment_tracker.py]
- 역할: 토론 중 주제 전환 및 감정 추적
- 기능:
  • 8-12개 메시지마다 랜덤하게 주제 자동 전환
  • 좌파/우파 논점에서 주제 추출
  • 50-80개 댓글 후 자동 종료
  • 다룬 주제 기록 및 관리

[persona/backend/models.py]
- 역할: 데이터 모델 정의 (Pydantic 기반)
- 기능:
  • AnalysisResult: 좌/우 논점, 감정 패턴, 샘플 댓글
  • DebateMessage: 토론 메시지 (성향, 내용, 주제, 타임스탬프)
  • DebateState: 토론 상태 (메시지 수, 현재 주제, 활성 여부)
  • CommentStats: 댓글 수집 통계
  • 모든 API 요청/응답 모델 포함

🌐 4. 페르소나 백엔드 API (FastAPI)
===================================================================================

[persona/backend/routes/persona.py]
- 역할: 페르소나 생성 API 엔드포인트
- 기능:
  • POST /api/comments/generate-persona - LLM 기반 페르소나 생성
  • 좌/우 댓글 각 5개 이상 필요
  • 생성된 페르소나는 토론에 사용

[persona/backend/routes/debate.py]
- 역할: AI 토론 시뮬레이션 API 엔드포인트
- 기능:
  • POST /api/debate/start - 토론 세션 시작
  • POST /api/debate/next - 다음 댓글 생성 (좌/우 번갈아)
  • GET /api/debate/status - 현재 상태 조회
  • POST /api/debate/reset - 토론 초기화

📰 5. 뉴스 팩트체크 시스템 (신뢰도 기반)
===================================================================================

[factcheck/models/document_source.py]
- 역할: 문서 소스 인터페이스 (추상 클래스)
- 기능:
  • Document 클래스 정의 (제목, 내용, 출처, 날짜, URL)
  • LocalDocumentSource: 로컬 JSON 파일 로드
  • DuckDuckGoSearchSource: 무료 웹 검색 (API 키 불필요)
  • HybridDocumentSource: 로컬 + 웹 통합
  • 모든 뉴스 소스의 공통 인터페이스

[factcheck/models/document_source_naver.py]
- 역할: 네이버 뉴스 검색 (한국 뉴스 특화)
- 기능:
  • 네이버 검색 API 사용 (NAVER_CLIENT_ID, NAVER_CLIENT_SECRET)
  • API 키 없으면 자동으로 크롤링 모드로 전환
  • 최신순 정렬
  • HTML 태그 제거 및 텍스트 정제
  • 키워드 추출 및 불용어 제거

[factcheck/models/document_source_universal.py]
- 역할: 한국 + 외국 뉴스 통합 검색
- 기능:
  • 네이버 (한국 뉴스) + DuckDuckGo (국제 뉴스) 병렬 검색
  • 키워드 자동 추출 (조사, 어미 제거)
  • URL 기반 중복 제거
  • 최대 20개 결과 반환 (각 소스당 10개씩)

[factcheck/models/evidence_searcher.py]
- 역할: 하이브리드 증거 검색 시스템
- 기능:
  • BM25 키워드 검색 (60%) + 임베딩 의미 유사도 (40%)
  • sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 사용
  • 문서를 문장 단위로 분할하여 스니펫 생성
  • 최소 관련도 임계값 0.65 (다양한 의견 수용)
  • 상위 5개 증거 반환

[factcheck/models/judge_local.py]
- 역할: 로컬 LLM 기반 판정 시스템 (API 키 불필요)
- 기능:
  • 3가지 모드: rule_based (기본), ollama, huggingface
  • 규칙 기반: 관련도 분석 후 Pending 반환 (실제 판정은 신뢰도에 위임)
  • 최소 관련도 0.5 이상 필요
  • 핵심 키워드 추출 (고유명사 우선)
  • Ollama/HF 실패 시 자동으로 규칙 기반으로 폴백

[factcheck/models/confidence_scorer.py]
- 역할: 신뢰도 평가 시스템 (1-10점 척도)
- 기능:
  • 룰 기반 점수 (0-8점): 출처 수, 최신성, 매칭 강도, 모순 여부
  • LLM 자기평가 (0-2점)
  • 최종 10점 만점으로 스케일링
  • 출처 2개 이상: +2점
  • 12개월 이내 최신: +1점
  • 매칭 강도: 증거 개수에 따라 차등 (1개: 최대 1점, 3개 이상: 최대 2점)
  • 모순 발견 시: -2점
  • 신뢰도 레벨: 매우 높음(8.5+), 높음(7+), 중간(5+), 낮음(3+), 매우 낮음

[factcheck/utils/text_processing.py]
- 역할: 텍스트 전처리 유틸리티
- 기능:
  • 문장 분할 (마침표, 물음표, 느낌표 기준)
  • 점수 정규화 (0-1 범위)
  • 불필요한 공백 제거

🧪 6. 팩트체크 실행 및 테스트 모듈
===================================================================================

[factcheck/main_universal.py]
- 역할: 범용 팩트체크 메인 실행 파일
- 기능:
  • CLI 인터페이스 제공
  • 단일 주장 팩트체크: --claim "주장 내용"
  • 배치 처리: --batch claims.json
  • 한국 + 외국 뉴스 모두 검색
  • 신뢰도 기반 최종 판정:
    - 5.5 미만: False
    - 5.5-7.0: Uncertain
    - 7.0 초과: True
  • 결과를 JSON 파일로 저장

[factcheck/batch_test.py]
- 역할: 여러 루머 케이스 일괄 테스트
- 기능:
  • rumor_test_cases.json에서 8개 테스트 케이스 로드
  • 각 케이스별 팩트체크 자동 실행
  • 카테고리별 분류 (정치, 경제, 사회 등)
  • 증거 상세 내용 출력 (제목, 날짜, 관련도)
  • 판정 통계 요약 (True/False/Uncertain/Error 개수)
  • batch_test_results.json 저장

📁 프로젝트 전체 흐름 요약
===================================================================================

1단계: YouTube 댓글 수집
   extract_comments.py → 댓글 다운로드 → extract_comments/*.txt

2단계: 댓글 주제 분석
   comments_topic.py → 토픽 모델링 → comments_result/*.txt

3단계: 페르소나 생성
   comment_persona_engine.py → LLM 학습 → 좌/우 페르소나 JSON 생성

4단계: AI 토론 시뮬레이션
   ai_debater.py → 페르소나 기반 댓글 생성 → 실시간 토론

5단계: 뉴스 팩트체크 (선택)
   main_universal.py → 뉴스 검색 → 증거 수집 → 신뢰도 평가 → 판정

===================================================================================
🔧 핵심 기술 스택
===================================================================================

• 자연어 처리: BERTopic, HDBSCAN, SentenceTransformer
• LLM 모델: skt/kogpt2-base-v2 (CPU 최적화)
• 검색 엔진: BM25, DuckDuckGo, 네이버 API
• 음성 인식: Whisper (OpenAI)
• 웹 프레임워크: FastAPI
• 데이터 검증: Pydantic
• YouTube API: google-api-python-client

===================================================================================
💡 주요 특징
===================================================================================

✅ API 키 선택적: 네이버/YouTube API 없어도 기본 작동 (크롤링/로컬 모드)
✅ CPU 최적화: 경량 모델 사용으로 GPU 불필요
✅ 모듈화: 각 기능이 독립적으로 실행 가능
✅ 한국어 특화: 한국 정치 댓글 및 뉴스에 최적화
✅ 자동화: 수집→분석→페르소나 생성→토론 전체 파이프라인
✅ 신뢰도 기반: 객관적인 증거 평가로 편향 최소화
